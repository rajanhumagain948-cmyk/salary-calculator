# 給与計算システム

## 実行

```bash
cd salary_calculator
python3 -m pip install -r requirements.txt
python3 main.py
```

`data/payroll.sqlite3` に会社情報、従業員、社員別雇用条件、勤怠、従業員×対象月の手当・控除・交通費、給与計算結果が保存されます。給与は「給与を確定」するまでPDF出力できません。「全社員を月次計算」は保存済みの社員別月次入力を使って全社員を計算します。所得税は国税庁の令和8年分月額表を `rules/2026/monthly_tax_table.csv` に変換して登録するまで、明細上0円かつ確定不可です。これは不正確な概算税額を給与明細に出さないためです。

## 年度ルール

各年度に `rules/YYYY/` を複製して料率・税表を追加し、対象年月と同じ年度を選びます。2026年度の初期ファイルは、協会けんぽ、厚生労働省、日本年金機構、国税庁の公表情報を出典としており、地域・事業区分・就業規則に応じた確認と更新が必要です。

## 現在の境界

固定残業・複数休憩・日跨ぎ・日／週残業・深夜・休日・複数手当／控除・CSV/PDF/SQLiteを実装しています。標準報酬の等級表、賞与、月60時間超、変形労働時間制、年末調整、住民税の自治体計算は、事業所ごとの適用条件が必要なためルール／入力拡張対象です。実運用前には社労士・税理士による検証をしてください。
