# 💰 給与計算システム

Pythonで開発した、従業員の勤怠・手当・控除などを管理し、月次給与を計算できる給与計算システムです。

## 🚀 実行方法

```bash
cd salary_calculator
python3 -m pip install -r requirements.txt
python3 main.py
```

## ✨ 主な機能

* 👤 会社・従業員情報の管理
* 🕐 勤怠管理
* ⏰ 残業・深夜・休日労働の計算
* 💰 手当・控除・交通費の管理
* 📊 月次給与計算
* 👥 全社員の月次給与計算
* 📄 給与明細PDF出力
* 📥 CSVデータ入出力
* 🗄️ SQLiteによるデータ保存

給与関連のデータは、

```text
data/payroll.sqlite3
```

に保存されます。

## 📊 給与計算

社員ごとの雇用条件・勤怠・手当・控除などをもとに月次給与を計算します。

「給与を確定」するまで給与明細PDFを出力できない仕組みにしています。

また、「全社員を月次計算」では、保存済みの社員別月次入力を使用して全社員の給与をまとめて計算できます。

## 📅 年度別ルール

年度ごとに給与計算ルールを管理できる構成にしています。

```text
rules/
├── 2026/
│   └── monthly_tax_table.csv
└── YYYY/
```

2026年度の初期ルールでは、以下の公表情報を参考にしています。

* 協会けんぽ
* 厚生労働省
* 日本年金機構
* 国税庁

料率・税額表などは年度や事業所の条件によって異なるため、実際の運用では最新情報を確認する必要があります。

## ⚠️ 注意事項

本システムは学習・開発目的の給与計算システムです。

給与・社会保険・税金に関するルールは、年度・地域・事業所・従業員の条件によって異なる場合があります。

実際の給与計算業務で使用する場合は、最新の公的情報を確認し、必要に応じて社労士・税理士などの専門家による検証を行ってください。
